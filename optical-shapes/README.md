# Optical Shapes

Láminas Ópticas, Gradient Shapes, Dot Shapes y Mix Shapes en un solo archivo (`index.html`, sin build).
Es la misma página publicada como artifact en claude.ai: https://claude.ai/artifact/LFni9jikP5hasdNXCUrwyo

- Abrilo directo en el navegador o con cualquier server estático.
- La UI sigue el kit de Extrude That (`ui-kit/`: reglas, tokens e íconos).
- La descarga de archivos usa la capability `downloads` del artifact; fuera de claude.ai el botón avisa que no está disponible.
- Para republicar el artifact desde Claude Code: publicar `optical-shapes/index.html` con la URL de arriba.
